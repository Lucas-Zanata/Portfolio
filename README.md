# Portfólio — Lucas de Bem Zanata

Portfólio pessoal desenvolvido para apresentar minha identidade profissional, formação, stack técnica e projetos práticos enquanto desenvolvedor Fullstack.

🔗 **Live:** [portfolio-lucas-zanata.vercel.app](https://portfolio-lucas-zanata.vercel.app)

## 📸 Preview

Tema escuro, tipografia forte e uma "janela de código" na hero mostrando uma classe Java com meu perfil — conectando o design diretamente com minha stack.

## ✨ Funcionalidades

- **Identidade profissional** — quem sou e o que faço, com ícones interativos de cada tecnologia
- **Filtro por tecnologia** — clique em um ícone da stack e veja quais projetos usam aquela tecnologia
- **Resumo profissional** — trajetória acadêmica em formato de timeline
- **Cursos e certificações** — accordion expansível com detalhes de cada curso
- **Projetos** — cards com links diretos para os repositórios no GitHub
- **Totalmente responsivo** — funciona bem em desktop e mobile
- **Copiar e-mail com 1 clique** na seção de contato

## 🛠️ Tecnologias utilizadas

Construído com **HTML, CSS e JavaScript puros** (sem frameworks ou build tools):

- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS, animações)
- JavaScript vanilla (filtros interativos, accordion, scrollspy, typewriter effect)
- Google Fonts (Space Grotesk + JetBrains Mono)

## 🚀 Deploy

Hospedado na **Vercel**, com deploy automático a cada `git push` na branch `main`.

## 📁 Estrutura do projeto

```
Portfolio/
├── index.html      # estrutura e conteúdo da página
├── style.css        # estilos e tema
├── script.js         # interatividade (filtros, accordion, animações)
└── README.md
```

## 🚀 Rodando localmente

Como é um projeto estático, não precisa de instalação nem dependências:

```bash
git clone https://github.com/Lucas-Zanata/Portfolio.git
cd Portfolio
```

Depois é só abrir o `index.html` no navegador, ou usar um servidor local simples:

```bash
python3 -m http.server 8000
```

E acessar `http://localhost:8000`.
